# 화면용 글꼴

`PretendardVariable.woff2`는 [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard)의 v1.3.9 배포 파일을 수정 없이 보관한 것이다.

- 원본: `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`
- 라이선스: 동봉한 `Pretendard-LICENSE.txt` (SIL Open Font License 1.1)
- 사이트 UI에서 가중치 100~900을 사용하고 같은 출처에서 제공한다. 브라우저가 외부 글꼴 CDN에 접속하지 않는다.
- `font-display: swap`으로 글꼴 로드를 기다리는 동안에도 내용을 표시한다.
- 작가가 만든 캔버스·카드의 기존 `sans-serif` 지정은 보존한다.
