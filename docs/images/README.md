# 문서 이미지

[프로젝트 README](../../README.md)와 [주요 화면 모음](../screens.md)에서 사용하는 이미지입니다. 배너는 문서용 일러스트이고, 화면 이미지는 2026-10-18에 확인한 배포 화면을 바탕으로 한 [Figma UI 문서](https://www.figma.com/design/Y4orK4LUYK19NXmVlmskdV/mystery-mango)에서 가져왔습니다. 화면 본문의 UI 기준일은 유지하며, 배너와 로고의 브랜딩 동기화일은 2026-10-28입니다.

## README 배너

[readme-banner.png](readme-banner.png)는 2026-10-27에 기본 이미지 생성 도구 `image_gen`으로 제작한 1730 × 909 PNG입니다. [참고 저장소](https://github.com/laetipark/mobinogi-web)의 캐릭터·타이틀 중심 배너 구성에 맞춰, 미스터리 망고의 초록색·망고색과 망고 탐정·카드·주사위를 사용했습니다. 문서 표지용 그림이며 서비스 UI 또는 Figma 화면 캡처가 아닙니다.

실제 사용한 [생성 프롬프트](banner-prompt.txt)를 함께 보관합니다. 이 배너는 루트 README, 문서 허브, 프런트엔드 README에서 공통으로 사용합니다. 교체할 때는 제목의 가독성과 작은 화면에서의 잘림 여부를 확인합니다.

2026-10-28에는 Figma의 `00 사업 개요 · 서비스 지도` 페이지에 [편집 가능한 배너](https://www.figma.com/design/Y4orK4LUYK19NXmVlmskdV/mystery-mango?node-id=147-6)를 구성했습니다. 제목은 Pixelify Sans Bold 텍스트, 배경과 장식은 SVG 벡터, 망고 탐정 캐릭터는 독립 PNG 레이어입니다. 문서에 삽입하는 `readme-banner.png` 원본은 유지합니다.

[banner-decoration.svg](banner-decoration.svg)는 배경과 장식을 직접 제작한 문서용 벡터 편집 소스입니다. 제목과 캐릭터를 제외한 1730 × 909 크기의 배너 구성 요소를 담으며, Figma에서는 제목 텍스트와 캐릭터 이미지 레이어를 함께 편집합니다.

## 사이트 로고

[mango-detective.png](../../frontend/public/images/mango-detective.png)는 README 배너의 망고 탐정 캐릭터를 참고해 기본 이미지 생성 도구 `image_gen`으로 만든 1254 × 1254 투명 PNG입니다. 망고 얼굴·탐정 모자·초록 잎·돋보기를 남긴 로고이며 [실제 생성 프롬프트](logo-prompt.txt)를 함께 보관합니다.

사이트 헤더, 홈의 제작 화면 예시, 스튜디오 상단과 브라우저 파비콘이 같은 파일을 사용합니다. 헤더에서는 서비스 이름이 링크의 접근 가능한 이름을 제공하므로 캐릭터 이미지의 대체 텍스트는 비워 중복 읽기를 피합니다. 교체할 때는 흰색·차콜색 배경과 모바일 크기에서 투명 배경, 비율, 식별성을 확인합니다.

2026-10-28에는 Figma 화면의 기존 로고 34곳을 같은 망고 탐정 캐릭터로 교체했습니다. 사이트 헤더 24곳은 42px, 스튜디오 상단 6곳은 34px, 제작 예시 4곳은 24px의 정사각형으로 배치했습니다.

## 화면 이미지 갱신 방법

1. 배포 화면 또는 로컬 개발 화면 중 어느 상태를 담는지 확인하고, UI 기준일과 브랜딩만 갱신한 날짜를 구분합니다.
2. Figma의 대응 프레임을 최신 화면에 맞추고 하단 누락·겹침과 원래 가로·세로 비율을 확인합니다.
3. 가능한 경우 프레임을 원래 크기의 PNG로 직접 내보냅니다. 직접 내보내기를 사용할 수 없으면 Chrome에서 프로토타입을 100% 배율로 표시해 캡처합니다. 긴 화면은 겹치는 영역을 맞춰 스크롤 캡처를 연결하고 상단·하단 누락과 중복을 확인합니다.
4. 기존 파일명과 가로·세로 비율을 유지합니다. 홈 첫 화면은 JPEG, 나머지 화면은 PNG로 저장하며 확장자와 실제 파일 형식을 맞춥니다. 이 목록의 획득 방식·치수와 [화면 모음의 기준일·운영 반영 범위](../screens.md#이미지-기준과-갱신)를 함께 갱신합니다.
5. README·문서에서 이미지가 열리는지 확인합니다. Figma의 임시 다운로드 주소와 로컬 임시 경로는 본문에 사용하지 않습니다.

서비스 글꼴은 Pretendard이며, Figma에서 사용한 대체 글꼴은 Noto Sans KR입니다. 문서 이미지에 실제 게임의 개인 비밀·엔딩 본문이나 계정의 민감 정보를 추가하지 않습니다.
