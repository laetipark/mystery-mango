# 클래식 보드게임

자유 오목·리버시·체커는 2인 자동 규칙 게임이다. 기본 공개 작품으로 바로 플레이하거나 제작 스튜디오에서 같은 규칙의 새 작품을 만들어 소개·게임판·말 색상·장면을 바꿀 수 있다. 임의 규칙 변경이나 AI 상대는 포함하지 않는다. 혼자 시험에서는 가상 좌석 두 개를 번갈아 조작한다.

## 채택 규칙

| 유형·엔진 | 규칙 |
| --- | --- |
| `GOMOKU` · `gomoku-v1` | 15×15, 첫 번째 좌석 선공. 빈 칸에 번갈아 두어 가로·세로·대각선으로 **5개 이상** 연결하면 승리한다. 금수·삼삼 제한·Swap2 오프닝은 없다. 빈 칸이 사라지면 무승부다. |
| `REVERSI` · `reversi-v1` | 8×8 중앙에 두 색을 2개씩 놓고 시작한다. 새 말과 기존 자기 말 사이에 연속된 상대 말을 모두 뒤집는다. 뒤집을 말이 없는 착수는 금지한다. 둘 곳이 없으면 서버가 차례를 넘기고, 양쪽 모두 둘 곳이 없으면 말이 많은 쪽이 승리한다. 동수는 무승부다. |
| `CHECKERS` · `checkers-v1` | 잉글리시 체커의 8×8 판과 각 12개 말. 어두운 칸만 쓰며 일반 말은 전진 대각선 한 칸, 킹은 앞뒤 대각선 한 칸 이동한다. 포획할 수 있으면 반드시 뛰어넘어 잡고, 같은 말로 가능한 연속 포획을 마친다. 여러 포획 경로 중 하나를 선택할 수 있다. 일반 말이 끝줄에서 승급하면 그 차례를 마친다. 상대가 둘 수 없거나 말이 없으면 승리한다. 같은 판·차례가 세 번 반복되거나, 양측 각 40차례 동안 일반 말의 전진과 포획이 모두 없으면 자동 무승부다. |

체커의 첫 좌석은 아래쪽에서 위로 전진한다. 연속 포획 도중에는 같은 말만 선택할 수 있다. 반복과 무진행 횟수는 완성된 차례만 센다. 오목은 대회용 렌주·정확히 다섯 개 규칙과 구분하여 **자유 오목**으로 표시한다. 체커의 무승부는 심판에게 청구하는 절차 대신 서버가 자동 적용한다. 세 게임 모두 차례 시간 제한이 없으며 명시적 탈퇴는 기권, 연결 끊김은 기존 복구·중단 정책을 따른다.

## 서버와 화면

차례, 허용 수(`legalMoves`), 말 배치, 자동 패스, 포획, 승패는 Java가 계산한다. 프런트는 받은 허용 수를 표시하고 좌표 명령만 보낸다. 오목·리버시는 `PLACE {row,col}`, 체커는 `MOVE {fromRow,fromCol,toRow,toCol}`을 사용한다. 좌표는 0부터 시작한다. 말·목적지 선택은 마우스와 터치, 키보드 버튼으로 조작한다.

실제 게임과 가상 좌석 시험은 같은 엔진을 사용한다. 명령은 현재 상태 버전과 멱등 키를 검사하고 PostgreSQL 트랜잭션으로 확정한다. 서버 재조회 시 말 배치와 차례를 복원하며, 다른 사람의 차례에는 허용 수를 반환하지 않는다. 기본 작품과 작가 작품 모두 정확히 2명으로 모집·초대·자동 매칭한다. 머더미스터리 노출 이력 때문에 반복 참가가 제한되지 않는다.

## 자료 제작과 참고

이 구현은 전통 게임의 규칙을 바탕으로 설명문과 단순 도형을 직접 작성했다. 특정 상용 제품의 보드·말 그림·로고·설명문을 복제하지 않았고 외부 이미지·음원을 번들하지 않는다. 리버시는 일반 명칭을 사용한다. 사용자가 올리는 디자인의 권리까지 보증하는 뜻은 아니다.

미국 저작권청은 게임 아이디어와 플레이 방법을 저작권 보호 대상에서 구분하고, 표현된 설명문·그림은 보호될 수 있다고 안내한다. 이는 모든 국가의 상표·특허까지 없다는 보증이 아니다. [미국 저작권청 게임 안내](https://www.copyright.gov/register/tx-games.html)

- 오목의 기본 판과 연결 규칙은 [RIF 기본 설명](https://www.renju.net/rules/)을 참고했다. 이 서비스는 위 표의 자유 오목 변형을 채택하며 [RIF 대회 규칙](https://gomoku.renju.net/gomokurules/)의 정확히 5개·Swap2와 다르다.
- 리버시의 뒤집기·패스·종료 판단은 [WOF 규칙](https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english)을 참고했다. 해당 페이지의 상표·그림·원문은 사용하지 않는다.
- 체커의 이동·포획·승급·승패·무승부는 [WCDF 잉글리시 체커 규칙 1.15~1.32](https://wcdf.net/rules/rules_of_checkers_english.pdf)을 참고했다. 시간제한·심판·대회 운영 절차는 구현 범위에 포함하지 않는다.
